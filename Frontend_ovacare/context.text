## Ovacare MVP — Setup Summary for Future Reference

### Step 1: Project Scaffolding
```bash
npm create vite@latest . -- --template react-ts
```
Created a React + TypeScript project using Vite in the current directory.

### Step 2: Dependencies Installed
```bash
npm install
npm install -D tailwindcss @tailwindcss/vite
npm install react-router-dom@6
```
- **Tailwind CSS v4** + Vite plugin (`@tailwindcss/vite`)
- **React Router DOM v6** (installed but not yet wired up)

### Step 3: Vite Configuration
**File: `vite.config.ts`**
Added the Tailwind CSS Vite plugin:
```ts
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

### Step 4: Tailwind v4 Theme Configuration
**File: `src/index.css`**
Tailwind v4 uses CSS-based configuration (not `tailwind.config.js`):
```css
@import "tailwindcss";

@theme {
  --color-primary-100: #EEF2EE;
  --color-primary-500: #5C7A5C;
  --color-primary-600: #4A6A4A;
}
```
These CSS variables enable `bg-primary-100`, `text-primary-500`, `text-primary-600` etc.

### Step 5: Clean App.tsx Placeholder
**File: `src/App.tsx`**
```tsx
function App() {
  return (
    <div className="min-h-screen bg-primary-100 flex items-center justify-center">
      <h1 className="text-3xl font-bold text-primary-600">

    </div>

```

### Step 6: Boilerplate Cleanup
Removed unused files:
- `src/App.css`
- `src/assets/react.svg`

### Key Lesson Learned
**Tailwind v4 changed configuration entirely.** The traditional `tailwind.config.js` is ignored. Custom theme values must be defined using `@theme` blocks in CSS with `@import "tailwindcss"` instead of the old `@tailwind base/components/utilities` directives.
